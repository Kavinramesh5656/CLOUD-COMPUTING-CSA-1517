# StudyBuddy Cloud Adaptive Tutor for CSA1517 Using CO-Wise Mastery Analytics

## Project Overview

StudyBuddy Cloud Adaptive Tutor is a cloud-based learning platform developed for the CSA1517 course. The system helps students improve their understanding by providing personalized learning resources, quizzes, and performance tracking based on Course Outcomes (COs).

The application uses CO-wise Mastery Analytics to analyze each student's performance for every course outcome. Based on the analysis, it identifies weak areas and recommends suitable study materials, practice questions, and learning activities.

Cloud computing enables the application to provide secure storage, real-time access, scalability, and anytime-anywhere learning. REST APIs are used for communication between the frontend, backend, and cloud database, ensuring efficient data exchange and personalized learning experiences.
